# 声音波形生成器

一个简单而强大的工具，用于生成和播放不同频率的立体声音频。

## 功能特点

- 生成任意频率的正弦波
- 分别控制左右声道的频率
- 实时播放立体声音频
- 简单易用的命令行界面

## 安装要求

使用本工具需要安装以下依赖：

```bash
pip install numpy sounddevice
```

## 使用方法

1. 运行程序：

```bash
python sound.py
```

2. 按提示输入左右声道的频率（单位：Hz），用逗号分隔：

```
请输入左右声道频率（Hz，用逗号分隔）：440,432
```

3. 程序将开始播放音频。使用 Ctrl+C 停止播放。

## 应用场景

- 音频测试和校准
- 音乐理论和声学研究
- 双耳节拍（Binaural Beats）生成
- 声音治疗和冥想辅助

## 示例用法

1. 标准A音（440Hz）：`440,440`
2. 双耳节拍（差8Hz）：`440,432`
3. 低频测试：`50,50`
4. 高频测试：`10000,10000`

## 代码结构

- `generate_stereo_wave()` - 生成指定频率的立体声波形
- `play_stereo_audio()` - 播放立体声音频

## 进阶应用

您可以修改代码以实现更多功能：

- 调整波形振幅（当前设置为0.3）
- 更改波形类型（当前为正弦波，可以改为方波、三角波等）
- 添加淡入淡出效果
- 实现频率扫描功能
